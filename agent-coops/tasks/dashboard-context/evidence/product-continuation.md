# Dashboard 上下文产品续接复核

这是新 Product 在独立工作区完成的实际输入复核。本文保存产品事实、证据范围和续接条件；尚未正式 publish 或 confirm，不表示产品设计已确认。需求和用户验收继续以原飞书任务为正本。

## 产品设计

复核对象为原需求、2026-10-08 历史实现记录、2026-10-15 HTML 设计试点、C1–C8、现有源码和自检源码。来源路径、读取摘要、真实会话与旧 owner 记录见[产品续接结构化证据](product-continuation.json)。原始飞书回读与交接材料保留在本机受控位置；本公开仓只记录必要事实及摘要。

原需求保留两个目标：选择项目后了解全部预加载上下文；查看 Codex 会话实际注入的完整上下文。用户后来指出配置文件难以理解，要求先交付设计与 HTML 交互原型。用户评审原型后，才可设计生产摘要能力及页面实现。迁移不能把这项条件替换为 Agent 检查通过。

| 用户目标 | 现有输入支持的结论 | 本轮结论 |
| --- | --- | --- |
| 不先读配置即可理解项目 | HTML 提供项目概览、工作要求、当前任务、可用能力和信息缺口；每项可以查看依据或明确缺口 | 方向与原需求一致；可理解性仍需用户评审 |
| 知道内容来自哪里 | 原型依据面板显示说明、来源类型、示例路径、摘录和示例读取时间 | 保留来源追溯；来源顺序不代表规则优先级 |
| 知道项目当前任务 | 原型要求明确选择任务；无任务时提示缺失 | 保留显式选择；不得按最近修改时间推断任务 |
| 区分可读文件与实际会话输入 | 文件清单、已保存会话记录和新建输入预览分开呈现 | 这些对象不能互相证明完整性；可用技能也不等于本轮已加载 |
| 查看实际完整输入 | 原源码仅输出文件清单、局部记录和新会话输入列表 | 已有会话完整请求导出仍未实现；不得关闭原需求 |

现有原型使用两个虚构项目和人工说明。它保留成功、失败、重试、空状态、依据缺失及项目切换。没有证据支持将这些示例摘要当作生产摘要。旧 TODO 的语言、同步和原话列表勾选保留历史意义；它们不能使本任务两条未完成目标通过验收。

## 架构设计

本节复核已有边界，不提出生产摘要方案。

| 已读取的输入 | 实际能力或合同 | 不能据此证明 |
| --- | --- | --- |
| `docs/prototypes/project-context.html` | 独立 HTML，内含虚构数据、CSS 和原生 JavaScript；不调用本机接口 | 真实项目采集、摘要准确性、脱敏或实际完整请求 |
| `scripts/dashboard-context.mjs` 与 `/api/context` | 显式项目的文件清单；返回 `coverage: file-inventory`；记录读取状态并执行路径边界检查 | 文件已被模型加载，或加载顺序与覆盖范围完整 |
| `scripts/dashboard-sessions.mjs` 与会话接口 | 按项目选择已保存记录；返回 `coverage: recorded-messages`、`complete: false`；记录压缩与损坏行 | 任意一轮的完整模型输入或完整 API 请求 |
| `captureCodexInput` 与 `/api/codex-input` | 在选定项目执行 `codex debug prompt-input`；接受输入数组；返回 `coverage: native-new-session-input-list`、`complete_request: false` | 指定已有会话或每轮请求的重建；当前工具版本的全部能力 |
| `site/js/app.js` | 分别显示上述三类数据；切换项目后忽略旧响应；真实导出需用户点击 | 已实现自然语言项目摘要、任务识别或冲突处理 |

这些源码和原型属于原 checkout 的未提交工作。本轮只读取并计算 SHA-256；没有把它们搬入当前候选，也没有验证运行中的服务。当前工作区没有历史原型和新增上下文模块，不能把本轮文档提交当作功能迁入完成。

继续保留本地与公开数据隔离：真实配置和会话内容不得写入公开 `site/data.json`；公开站点不得读取 Team 私有正文。文件读取、会话记录和新建预览应保留来源与完整性标签。未来生产设计必须处理摘要依据、缺失与冲突、任务归属、项目切换、脱敏及实际输入采集边界。该设计等待原型用户评审，本轮不提前选方案。
