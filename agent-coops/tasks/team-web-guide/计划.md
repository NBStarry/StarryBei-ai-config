## 架构设计

### 单文件实现

唯一生产修改文件为 `site/workflow.html`。保留原路径，使用静态 HTML 与一个主内容区域，显示简短迁移卡片。页面保留 `lang="zh-CN"`、UTF-8 和 viewport 声明；title 与唯一主标题使用中文迁移说明。

复用已有 `css/style.css?v=20261008` 和 `css/workflow.css` 引用，不修改两份 CSS。共享样式提供颜色、字体、reset、`:focus-visible` 和文档基础排版。仅在本页的 style 内补充卡片最大宽度、留白、入口间距和移动换行。样式使用本页专属类限定作用范围，内容宽度不超过视口，长文字允许换行。

把原目录、多章节团队正文、流程与安装说明替换为产品确认内容。移除本页主题按钮及 `js/workflow-doc.js` 引用；原脚本和旧 CSS 文件保持原字节。迁移页使用共享 CSS 的默认主题，不增加主题状态或脚本。

三个入口均使用具有实际 href 的 `a` 元素。采用正常文档顺序与共享焦点样式，不用 disabled 按钮、点击事件或正 tabindex 代替链接。无需设置新窗口。页面不增加 JavaScript、接口、iframe、私有内容抓取或自动跳转。
